# 💰 SpendSmart

**SpendSmart** is a personal finance management application designed to help users track their expenses, manage budgets, and understand their spending habits through a simple and intuitive interface.

## ✨ Features

* 📊 **Expense Tracking** — Record and categorize daily expenses.
* 💵 **Budget Management** — Set budgets and keep track of spending.
* 📈 **Spending Insights** — Understand where your money is being spent.
* 🗂️ **Expense Categories** — Organize transactions into meaningful categories.
* 📅 **Transaction History** — View and review previous expenses.
* 📱 **Responsive UI** — Designed to work across different screen sizes.
* 🔐 **User Accounts** — Keep personal financial data associated with the user's account.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd SpendSmart
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local development URL shown in the terminal.

## 🎯 Project Objective

Managing everyday expenses can become difficult when spending is spread across multiple categories and transactions.

SpendSmart aims to provide a centralized platform where users can **record expenses, monitor budgets, and gain a clearer understanding of their financial habits**.
